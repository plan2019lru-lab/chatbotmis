# ผู้ช่วยระบบคำของบประมาณ (MIS Budget Chatbot)

ระบบแชทบอทและคู่มือแนะนำการใช้งานระบบคำของบประมาณ มหาวิทยาลัยราชภัฏเลย ตามคู่มือฉบับทางการ 120 หน้า

## คุณสมบัติเด่น
- ?? **โหมดออฟไลน์ 100% (Client-side):** ไม่ต้องพึ่งพา External AI API หรือ API Key ใดๆ ปลอดภัย ไร้ปัญหาเซิร์ฟเวอร์ล่ม
- ??? **ภาพประกอบหน้าจอจริงจากคู่มือ:** มีภาพแคปหน้าจอจริงความคมชัดสูงทั้ง 120 หน้า พร้อมปุ่มขยายดูแบบเต็มจอ (Lightbox Modal)
- ?? **ลิ้นชักเปิดอ่านคู่มือ (Manual Preview Drawer):** คลิกที่เลขหน้าอ้างอิงเพื่อเปิดดูหน้าคู่มือต้นฉบับจริง พร้อมปุ่มนำทางพลิกหน้า
- ?? **ระบบค้นหาหัวข้อคำถามแบบเรียลไทม์:** จัดหมวดหมู่คำถามตามระดับความชำนาญ (ระดับ 1 มือใหม่ ถึงระดับ 4 ขั้นสูง)
- ?? **ปุ่มคัดลอกคำตอบในคลิกเดียว:** อำนวยความสะดวกในการนำคำตอบไปใช้งานต่อ
